# Recorded v0.2 outputs

This folder includes compact result tables from the recorded exploratory run:

- `entropy_agency_v0_2_final_summary.csv`: scenario-level outcomes.
- `entropy_agency_v0_2_cognitive_ablation.csv`: paired cognition-enabled versus cognition-disabled comparisons.
- `entropy_agency_v0_2_albedo_off_summary.csv`: albedo-feedback sensitivity summary.

The full generation-by-generation time series, run metadata and plots are regenerated by running the main simulation. They are not committed in this initial import to keep the repository lean and avoid treating a large stochastic trace as a canonical dataset.

From the repository root:

```bash
python -m pip install -r requirements.txt
python entropy_agency_sim_v0_2.py --output-dir results
```

The albedo-off sensitivity can be rerun with:

```bash
python entropy_agency_v0_2_albedo_sensitivity.py
```
